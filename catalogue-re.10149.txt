社会保険管理システム

■目的
健康保険（協会けんぽ・組合健康保険）、介護保険、厚生年金保険における「計算の正確性」と「手続きの網羅性」を担保する。
複雑な社会保険業務において、個人毎の保険料および会社負担分を完全に可視化し、事業所・従業員の双方にとって不利益・ミスのない適正な社会保険運用を実現する 。

■データ定義
〇事業所データ（管理者が設定・入力）
    システムが自動計算する際に用いるマスタ情報
    ▷基本情報：届出等の出力の際に用いる情報
        所在地、事業主、各種事業所番号（法人番号や整理記号等）

    ▷保険料率・負担率の設定
        法改正や組合固有の規定に対応
        適応時期の入力によって、任意の値もアーカイブ化される
        ▷加入健康保険組合種別の選択：
            ▷協会けんぽ：事業所の所在地に基づき健康保険料率・介護保険料率を自動適用
            ▷組合健保：各健康保険組合固有の保険料率を任意の値で設定可能
        ▷厚生年金保険料：
            法令で定められた保険料率が自動適応
            厚生年金基金への加入がある場合、保険料率を任意の値に設定可能
        ▷労使折半率の登録
    
    ▷計算や運用の設定
        ▷支払基礎日数：「暦日基準」または「締め日基準」の選択 
        ▷徴収時期：保険料控除タイミングの選択（当月・翌月・翌々月）
        ▷特定被保険者徴収：特定被保険者から介護保険を徴収するか否かの選択
        ▷端数処理：法令基準（50銭基準）に加え、労使折半時の端数処理、独自の処理の設定

〇従業員データ（管理者が入力・インポート）
    ▷基本情報：閲覧および本人からの変更申請の承認
        氏名、生年月日、マイナンバー/基礎年金番号、扶養家族情報等
    ▷雇用情報：
        雇用形態、給与形態、出勤日数、就業状況（休業中、退職済等）
    ▷給与・賞与情報：月次または支払毎の入力
        基本給、各種手当（固定・変動・臨時）、遡及差額、現物支給額
    ▷標準報酬月額・標準賞与額の履歴管理：
        過去の等級情報を月次で保持し、過去に遡った保険料の確認や差異修正に対応。
    ▷データ入力方法：
        個別入力、複数選択による一括入力
        CSVファイルからのインポート

〇従業員データ（従業員自身が操作）
    ▷基本情報：
        サインアップ時に設定を行う
        

3. 従業員マイページデータ（従業員自身が操作） 

* 
**閲覧・申請:** 自身の給与明細・社保料の閲覧、通勤費・扶養家族情報の変更申請、休業の申出 。


* 
**【詳細化】同意確認フロー:** 年間平均による定時決定・随時改定が採択された際、システム上で従業員へ自動通知し、同意/異議申し立ての意思表示を記録 。

## ■ 機能要件

### 1. 【最重要】社会保険料・給与の自動算出（見える化の担保）

入力された給与・勤怠データ、および事業所マスタを基に、システムが各種保険料を自動算出する 。

* **【追加】保険料の内訳分離計算:**
個人ごとに「健康保険料」「介護保険料」「厚生年金保険料」**を算出し、それぞれ**「本人負担分」と「会社負担分」に完全分離して自動計算・保持する。
* 
**算出ロジック:** 定時決定（算定）または随時改定（月変）によって決定された「標準報酬月額」および「標準賞与額（1,000円未満切り捨て、上限あり）」に、指定の保険料率を乗じて算出.


* **端数処理:**
従業員負担分の給与控除時の端数処理（50銭基準/切り捨て等の独自規定）に加え、事業所負担分との折半計算における端数処理に対応 。



### 2. 【詳細化】自動判定および管理者へのアラート通知

実務の処理漏れを防ぐため、システムが自動で対象者をスクリーニングし、管理者に通知する 。

* 
**定時決定（算定基礎）:** 4〜6月の給与から標準報酬月額を自動試算。非対象者（育休者等）の自動判定・管理者通知、および「被保険者報酬月額算定基礎届」の一括出力 。


* 
**随時改定（月変）:** 固定的賃金の変動から3ヶ月間の支払基礎日数を満たし、2等級以上の変更該当者を自動抽出して管理者へ通知。「被保険者報酬月額変更届」の一括出力 。


* 
**特例随時改定:** 育休等の休業明け改定の条件を満たした対象者を自動判定・通知 。


* 
**年間平均:** 業務の性質上、定時・随時改定で通常計算を行うと著しく不公平となる場合、過去1年間の平均を用いる算定方法の採択判定。対象従業員への自動同意確認通知、および「様式1・様式2」の出力 。


* 
**賞与判定:** 支給回数を自動カウントし、年4回以上の場合は「報酬」として翌年の定時決定に自動算入する判定。通常賞与時は「被保険者賞与支払届」を出力 。


* 
**年齢判定:** 介護保険料の徴収開始・終了（40歳・65歳到達）、70歳（厚生年金免除）・75歳（健康保険喪失）到達時の保険料切替・免除の自動判定および事前アラート 。


* 
**得喪判定:** 同月内の資格取得・喪失や、月末・途中退職時の保険料計算、退職時の複数月（2ヶ月分）自動徴収の要否判定。「資格取得・喪失届」の出力 。



3. 閲覧・出力（データ連携） 

* 
**画面閲覧:** 社会保険料を期間、金額、保険種別、従業員、**【追加】本人・会社負担別**の要素で絞り込み・並び替え 。


* 
**帳票・データ出力:** * 年金事務所・健康保険組合提出用および電子申請用（e-Gov/マイナポータル連携等）CSV・PDF出力 。


* **【追加】「社会保険料 本人・会社負担内訳一覧表（部門別・勘定科目別）」のCSV/PDF出力（財務・経理部門への労務費・法定福利費連携用）**。



4. ヘルプ（動的解説・ナレッジ機能） 

* 
**動的解説機能:** 年齢到達や随時改定で保険料が変動した際、従業員の給与明細画面に「なぜ金額が変わったのか（例：40歳に達し介護保険料が発生したため）」の理由を自動表示し、人事への問い合わせを削減する 。


* 
**手続き解説:** 各種手続きの概要・法規解説リンクを画面内に常設 。



5. 監査ログ・証跡管理 

* 
**4W1Hの厳密な記録:** データに対する「作成」「更新（変更前後のデータ保持）」「削除」の操作ログを保持し、社内不正や入力ミスの原因究明を可能にする 。

## ■ システムフロー（月次業務ユースケース）

1. **初期設定**
* 管理者が「事業所アカウント」を立ち上げ、保険料率（協会または組合）を設定 。


* メールで従業員を招待し、各自がアカウントを作成（初回データ登録） 。




2. **月次データの入力・申請**
* 管理者が毎月の勤怠・給与データをCSVインポート 。


* 従業員からマイページを通じて、当月の休業申請や異動情報が送信され、管理者がシステム上で承認・確定を行う 。




3. **自動スクリーニング・試算**
* システムが自動で「随時改定」「年齢到達」「得喪」を演算 。


* 管理者へ手続き対象者のアラートが飛び、従業員明細へ自動変動理由がセットされる 。




4. **【追加】会社負担分の確認と月次確定**
* 管理者が当月の「個人毎の保険料」および「会社負担分（法定福利費）」の合計値を一覧表で確認。
* 管理者が月次確定ボタンを押し、該当月のデータをロック（過去データの改ざん・誤上書きを防止） 。




5. **明細公開・手続出力**
* 従業員が給与明細をマイページで確認 。


* 管理者が各種届出（算定基礎届・月変届等）や、電子申請用データ、経理連携用の一覧表を出力する 。
